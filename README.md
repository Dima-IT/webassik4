In this assignment, I created a simple website using HTML, CSS, Bootstrap and JavaScript.

I made different forms and added validation to check user input.

## Task 3 - Bootstrap Validation

In this task, I added validation using Bootstrap and JavaScript.

I used is-valid and is-invalid to show if the input is correct or incorrect.

If the input is correct, the border becomes green. If it is incorrect, the border becomes red and an error message appears.
